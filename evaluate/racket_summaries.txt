1. Recursive Factorial Calculation: Computes the factorial of a non-negative integer n using recursion. Returns 1 if n ≤ 1, otherwise returns n × factorial(n-1). Demonstrates basic recursive pattern.
2. Naive Fibonacci Implementation: Calculates the nth Fibonacci number using pure recursion without memoization. Has exponential O(2^n) time complexity due to redundant calculations.
3. Prime Number Check (Trial Division): Determines if a number is prime by testing divisibility from 2 to √n. Returns #t for primes, #f for composites. Simple but inefficient for large numbers.
4. String Reversal: Reverses a string by converting it to a character list, reversing the list, then converting back to string. Shows basic string/list manipulation.
5. List Flattening: Recursively flattens a nested list structure into a single-level list. Handles arbitrary nesting depth using car/cdr recursion.
6. Binary Search Algorithm: Efficient O(log n) search in sorted vectors. Returns index if found, #f otherwise. Demonstrates divide-and-conquer strategy.
7. Quicksort Implementation: Sorts a list using the quicksort algorithm with first element as pivot. Shows functional programming approach to sorting.
8. Matrix Multiplication: Multiplies two matrices using dot products. Assumes valid dimensions. Illustrates nested list operations.
9. Polynomial Evaluation (Horner's Method): Efficiently evaluates polynomials using Horner's rule (O(n) time). Coefficients ordered from highest to lowest degree.
10. Binary Tree Depth Calculation: Computes maximum depth of a binary tree represented as nested pairs. Recursively compares left/right subtree depths.
11. Graph Structure Validation: Checks if a graph representation is valid (list of edges). Verifies each element is a 2-item list.
12. List Membership Check (eq?): Finds first occurrence of an item in a list using eq? comparison. Returns sublist starting from match or #f.
13. List Deduplication: Removes duplicate elements from a list while preserving order. Uses foldr and member to build new list.
14. Permutations Generation: Generates all permutations of a list recursively. Shows combinatorial algorithm implementation.
15. Numerical Differentiation: Approximates derivative of function f at point x using finite difference (forward difference formula).
16. Numerical Integration (Rectangle Method): Approximates definite integral using rectangle rule with n partitions. Basic numerical integration technique.
17. Mandelbrot Set Iteration: Computes Mandelbrot iteration count for complex number c. Returns number of iterations until divergence (max 100).
18. String to Integer Conversion: Converts numeric string to integer using Racket's built-in string->number. Simple type conversion example.
19. Vector Element Swapping: Mutates a vector by swapping elements at indices i and j. Demonstrates vector reference/set operations.
20. Stack Data Structure: Implements stack with push, pop, peek and empty? operations using closure and list mutation.
21. Breadth-First Search (BFS): Traverses graph from start node using BFS. Returns nodes in visitation order using queue.
22. Depth-First Search (DFS): Traverses graph from start node using DFS. Returns nodes in post-order using recursion.
23. Queue Data Structure: Implements FIFO queue with enqueue/dequeue operations using two lists (front/rear).
24. A Pathfinding Algorithm: Finds optimal path between nodes using heuristic function. Shows priority queue usage.
25. Huffman Encoding: Builds Huffman coding tree from character frequencies. Demonstrates greedy algorithm for data compression.
